## Limitations and follow-ons

The unchanged lockfile has 10 reviewed development-tool advisories (4 moderate, 6 high); `npm audit --omit=dev` reports 0. No affected tool is added to the production bundle. Targeted toolchain maintenance needs separate verification and a newly tagged Worker because the lockfile contributes to its source tag. No blind upgrade was performed.

Interaction comparison (steps, not measured timings): single entries previously required Record → directory/search/select → quantity → save; from a member page, Record for this member → quantity → save. Groups previously required Record → split → select each person → quantities → review → confirm; a saved entry supplies Use these people → quantities → review → confirm. Login is still required without a session; unresolved durable attempts always take precedence.

Rollback must retain a compatible privacy-aware Worker and additive schema. Never automatically restore an old production snapshot or deploy the pre-crew Worker. Follow [the guarded recovery procedure](crew-release.md), preserving later accepted records.

Future work is recorded only: revocable editor invitations with owner authorization and audit design; approved photo storage/privacy; dynamic public previews if justified; a separate generalized product only if explicitly chosen. None is implemented in this release.
